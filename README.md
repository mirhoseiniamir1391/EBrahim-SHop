# فروشگاه جمهوری

## اضافه‌کردن عکس‌ها
1. عکس‌های واقعی را در پوشهٔ مربوط قرار دهید:
   - `images/stationery/` برای لوازم‌التحریر
   - `images/printing/` برای چاپ و کپی
   - `images/computer/` برای خدمات کامپیوتر
2. فایل‌های JPG، JPEG، PNG، WEBP، GIF و AVIF پشتیبانی می‌شوند. اسم فایل‌ها هرچه باشد مهم نیست.
3. در ویندوز روی `refresh-images.bat` دوبار کلیک کنید تا فهرست عکس‌ها خودکار ساخته/به‌روز شود. Python 3 باید نصب باشد.
4. پوشه‌ها و فایل‌های به‌روزشده را همراه سایت به GitHub ارسال کنید.
